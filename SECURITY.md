# Security policy

SupplyGuard is currently an educational and portfolio project. Do not expose the MVP directly to the public internet without authentication, authorization, rate limits, TLS, security headers, and an explicit data-retention policy.

Please report security issues privately to the repository owner. Include the affected version, reproduction steps, impact, and any suggested mitigation. Do not include sensitive third-party SBOM data in a public issue.

See `docs/threat-model.md` for current controls and known limitations.
