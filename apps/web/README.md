# SupplyGuard web

SvelteKit interface for uploading CycloneDX JSON, viewing BSI profile findings, inspecting components and vulnerabilities, and exporting localized reports in English, German, or Russian.

```bash
npm ci
npm run dev
```

Set `PUBLIC_API_BASE_URL` when the API is not available at `http://localhost:8000`.

```bash
npm run check
npm run build
```
