# Contributing

1. Create a focused branch.
2. Keep profile changes explicit: update `profile.py`, validator rules, fixtures, tests, and `docs/bsi-profile.md` together.
3. Add or update tests for behavioral changes.
4. Run the API and web validation commands from the README.
5. Do not claim official BSI certification in code, documentation, or UI.

Use English for code, finding keys, API fields, and commit messages. User-facing text must remain available in English, German, and Russian.
